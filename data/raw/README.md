# Raw data

This directory is intentionally excluded from the public GitHub version of the project.

To reproduce the analysis locally, place the source files in the layout expected by the cleaning scripts:

- `qlfs_2023/q1/data/QLFS202301.csv`
- `qlfs_2023/q2/data/QLFS202302.csv`
- `qlfs_2023/q3/data/QLFS202303.csv`
- `qlfs_2023/q4/data/QLFS202304.csv`
- `lmdsa_2023/data/LMD2023.csv`

The repository can still be used as a portfolio artifact without these files because the scripts, lighter-weight outputs, and final report remain available.
